# 라이선스와 공개 준비

MotionMate 캐릭터 웹사이트를 공개하기 전에 확인할 Live2D 약관 판단, 코드에 반영한 내용, 체크리스트, 박람회·외주·유료화 검토를 정리한 문서입니다.

- 기준 약관:
  - Live2D Proprietary Software License v2.1 (Cubism Core)
  - Live2D Open Software License v1.4 (Cubism Framework)
  - 둘 다 2025-02-03 개정판
- 약관은 일본어 원문이 우선합니다 (Core 약관 15.2).
- 이 문서는 법률 자문이 아닙니다. 자격과 해당 여부의 최종 판단은 Live2D 재량입니다 (2.2).

## 1. 공개(출판) 라이선스 판단

| 항목 | 판단 | 근거 |
|---|---|---|
| 웹사이트 공개 | 웹에 공개하는 것도 "출판"입니다. 박람회 전시와 시연도 포함 | 1.6, 1.12 |
| 운영자 구분 | 1인 개인, 상업 매출 1천만 엔 미만 → **일반 사용자** | 1.21 |
| 출판 허락 계약·비용 | **면제** (확장성 앱이 아닐 때) | 2.2 |
| 무료·유료 | 면제에는 유료·무료 조건이 없음 | 2.1, 2.2 |
| 매출이 1천만 엔을 넘으면 | 다다음 달 말일까지 Live2D에 통지하고, 넘은 달부터 소급해 계약 | 2.2 |

- 매출은 이 사이트만이 아니라 **상업 활동 전체** 기준입니다. 리깅 외주 수입도 포함됩니다.
- 회사 업무나 회사 장비와 섞지 않습니다. 회사를 위해 쓰면 회사가 "고객"에 포함되어 회사 매출이 기준이 됩니다 (1.3).

## 2. 확장성 애플리케이션

해당하면 개인도 면제가 없습니다. 출시 전 신청과 승인, 별도 계약이 필요하고, 공식 안내상 완전 무료는 원칙적으로 승인 대상이 아닙니다.

| 구성 | 판단 |
|---|---|
| **사이트 하나에 내 캐릭터 1개 고정** (지금 구조) | 해당하지 않을 가능성이 높음 |
| 캐릭터별로 도메인을 나눈 사이트 여러 개 | 각각 독립된 작품. 한 사이트에서 여러 캐릭터를 골라 보는 뷰어로 합치면 포털·컬렉션 조항에 가까워짐 |
| 운영자가 업데이트로 캐릭터 추가 | 정해진 수의 캐릭터라 "불특정 다수"가 아님. 다만 서로 다른 작품을 모으는 형태는 주의 |
| 얼굴 따라하기 | 2026-10-08 요청으로 구현. 고정된 단일 모델의 따라하기만으로 확장성 앱이 되는지는 공개 자료로 확정할 수 없음. 무료 면제를 단정하지 않고 공개 전 Live2D에 분류 문의 |
| 방문자가 자기 모델을 올려서 보는 기능 | **해당함** (nizima 모델 사양 문서에도 같은 취지로 명시) |

## 3. 코드와 문서에 반영한 것

| 약관 조항 | 반영 |
|---|---|
| 5.3.1 계약 없이 작품 이름에 Live2D 상표 사용 금지 | 서비스 이름은 `src/config.ts`의 `SERVICE_NAME` 한 곳에서 관리. 약관 테스트가 문서 제목에 Live2D가 없는지 확인 |
| 5.2.2 최종 사용자가 Core 보호 조항에 동의 | [이용약관](../legal/terms_of_service.md) 제5~7조, 첫 방문 동의 화면 |
| 6.1, 6.2 Core 수정·공개 금지 | Core와 Framework는 저장소에 넣지 않음. `tool/prepare_cubism_web.py`로 로컬에만 준비. CI가 결과물에 SDK 파일이 없는지 검사 |
| 3.1, 6.5 SDK를 제3자 컴퓨터에 설치 금지 | 협업자는 각자 SDK를 받아 약관에 동의. SDK를 넣은 빌드는 자기 PC에서 |
| 6.8 플랫폼 정책·법령 준수 | [개인정보처리방침](../legal/privacy_policy.md). 선택적 카메라 처리, MediaPipe 성능·사용 지표, 접속 기록 고지. 카메라는 영상만 요청하고 마이크·위치는 차단 |
| 5.3.2, Framework 약관 5.6 다른 라이선스 적용 금지 | 저장소에 오픈소스 라이선스를 붙일 때 Live2D 코드는 범위에서 제외 |
| 14.2 Live2D에 제공한 코드는 권리 절반 양도 | Live2D 문의나 포럼에 이 저장소 코드를 붙여 넣지 않음 |

## 5. 박람회 시연과 리깅 외주

| 구성 | 판단 |
|---|---|
| 내 캐릭터 사이트 3개를 태블릿에 띄우고 QR로 관람객 휴대폰에서 보기 | 출판에 해당하지만 개인 면제 범위. 사이트마다 약관과 동의 |
| 리깅 외주 (Cubism Editor 작업) | 문제없음. 매출 1천만 엔을 넘으면 Editor PRO와 출판 계약 필요 |
| 외주 고객에게 단일 캐릭터 웹사이트 제공 | **조건부.** Core 약관 6.7(대리 사용 청부 서비스 금지)과 6.5(외주) 때문 |

외주 고객에게 사이트를 제공할 때는 다음 구조가 안전합니다.
1. 고객 본인이 Live2D SDK 약관에 동의합니다.
2. 사이트는 **고객 도메인에 고객 이름으로** 공개합니다.
3. 운영자는 만들어 주는 외주 개발자 역할만 합니다.
4. 고객이 회사이고 매출이 1천만 엔 이상이면 고객이 출판 계약을 맺어야 합니다.

**피할 구조:** 내 도메인 하나에 고객 캐릭터를 계속 추가해서 대신 호스팅하는 방식입니다.

## 6. Live2D에 문의할 내용

1. 캐릭터별 웹사이트를 박람회에서 태블릿과 QR로 시연하는 것이 개인 면제 범위인지
2. 리깅 외주 고객에게 단일 캐릭터 웹사이트를 만들어 주는 구조가 6.7에 걸리지 않는지
3. 모델이 고정된 얼굴 따라하기 기능이 확장성 애플리케이션에 해당하는지 (구현 완료, 판정 미확정)

얼굴 추적에는 MediaPipe Tasks Vision 1.1.0을 사용합니다. Apache License 2.0과 출처를 빌드의 `face/LICENSE.txt`, `face/NOTICE.txt`에 포함합니다.
모델은 Google의 공식 Face Landmarker float16 version 1을 빌드 시 내려받고 체크섬을 검증합니다. 입력 영상은 기기 내에서 처리합니다.
Google 안내에 따라 성능·사용 지표 처리 가능성을 개인정보처리방침과 동의 화면에 알리고, 동의 버전을 갱신했습니다.
Live2D와 MediaPipe의 라이선스 범위는 서로 다릅니다.

문의에는 구성 설명만 적고 코드는 보내지 않습니다. 확장성 애플리케이션 신청 양식: https://www.live2d.jp/eng/application-publication-license/form/

## 7. 유료화 검토 요약

| 방식 | 판단 |
|---|---|
| 내 캐릭터 고정 + 유료 기능 | 확장성 앱이 아니면 Live2D 수수료 면제. 웹 직접 결제는 사업자등록, 통신판매업 신고(규모에 따라 면제), 환불 규정, 결제 정보에 맞춘 방침 개정이 필요 |
| nizima 모델 가져오기 + 유료 기능 | 확장성 앱. 사전 승인, 계약, 판매 1건당 ¥300 또는 매출 20% 중 큰 금액, 매출 보고. 앱 안에서 nizima 상품을 사고 받는 공개 API는 확인하지 못함 |

Live2D와 nizima는 nizima 모델을 배경화면으로 쓰는 공식 앱 "My Live2D Clock"을 운영하고 있습니다. 비슷한 구조를 만들면 승인 심사에서 경쟁 관계가 고려될 수 있습니다.
