# 라이선스와 출시 준비

MotionMate를 출시하기 전에 확인해야 할 Live2D 약관 판단, 앱에 반영한 내용, 출시 체크리스트, 유료화 검토 결과를 정리한 문서입니다.

- 기준 약관: Live2D Proprietary Software License v2.1(Cubism Core), Live2D Open Software License v1.4(Cubism Framework). 둘 다 2025-02-03 개정판입니다.
- 약관은 일본어 원문이 우선합니다(Core 약관 15.2).
- 이 문서는 법률 자문이 아닙니다. 자격과 해당 여부의 최종 판단은 Live2D 재량입니다(2.2).

## 1. 출시 라이선스 판단

| 항목 | 판단 | 근거 |
|---|---|---|
| 개발자 구분 | 1인 개인, 상업 매출 없음 → **일반 사용자** | Core 약관 1.21 |
| 출판 허락 계약·비용 | **면제** (확장성 앱이 아닐 때) | 2.2 |
| 유료 앱·인앱결제 | 면제 상태에서도 가능. 상업/비상업으로 구분하지 않음 | 2.1, 2.2 |
| 매출이 1천만 엔을 넘으면 | 다다음 달 말일까지 Live2D에 통지하고, 넘은 달부터 소급해 계약 | 2.2 |

- 매출은 이 앱만이 아니라 **상업 활동 전체** 기준입니다. 프리랜서나 부업 매출이 있으면 합산될 수 있습니다.
- 회사 업무나 회사 장비와 섞지 않습니다. 회사를 위해 쓰는 것으로 보이면 회사가 "고객"에 포함되고 회사 매출이 기준이 됩니다(1.3).

## 2. 확장성 애플리케이션 위험

일본어 원문 정의(1.5):

> ファイルやデータの追加や組み合わせ等によって不特定多数のモデルやデータを利用および生成する派生作品（例：アバター、配信アプリ、動画生成ツール）、単一タイトルの中に複数の作品や別の作品を内包しているもしくは単一タイトルを通じてこれらにアクセスできる派生作品（例：関連作品のコレクションやポータル）

해당하면 개인도 면제가 없고, 출시 전에 신청해서 승인을 받은 뒤 별도 조건의 계약을 맺어야 합니다(2.1, 2.2).

| 기능 | 판단 |
|---|---|
| 캐릭터 1개 고정, 자이로·터치·흔들기 | 해당하지 않을 가능성이 높음 |
| 따라하기 (얼굴로 캐릭터 조종) | 원문 예시(アバター, 配信アプリ)와 겹치고 "데이터"까지 포함하는 문구라 **판정 위험이 있음** |
| Android 배경화면 | 같은 캐릭터를 재사용하므로 영향 없음 |
| 사용자가 모델을 추가하는 기능 | **해당함** |
| 캐릭터 여러 개 모음, 내려받는 캐릭터(DLC), 영상 녹화·내보내기 | 원문 예시와 겹침. 넣기 전에 확인 필요 |

**출시 전에 Live2D에 따라하기 포함 구성이 확장성 앱인지 문의합니다.** 문의할 때는 앱 설명만 보내고 소스 코드는 보내지 않습니다(14.2: 제공한 코드는 권리의 절반이 Live2D에 양도됨).

## 5. 유료화 검토: Live2D 캐릭터 스토어(nizima) 연동

nizima는 Live2D가 운영하는 공식 마켓입니다. 일러스트와 Live2D 모델을 사고팔고 주문 제작도 할 수 있습니다.

### 5-1. 기술적으로 연결되는가

- **앱 안에서 nizima 상품을 검색·구매·다운로드하는 공개 API는 찾지 못했습니다.**
- Live2D 공식 앱들도 nizima에서 산 모델 데이터를 파일로 받아 앱으로 가져오는 방식으로 안내합니다. 예를 들어 nizima LIVE TRACKER는 ZIP 가져오기를 씁니다.
- **nizima 모델 사양**(베타)은 Live2D 모델이 여러 앱에서 탭·플릭·표정에 반응하도록 하는 공통 사양입니다. 이 사양을 지원하면 nizima 대응 모델을 같은 방식으로 움직일 수 있습니다.
- 같은 사양 문서에 **"불특정 다수의 모델을 불러오는 앱을 출시하려면 확장성 애플리케이션 출판 허락 계약이 필요하다"**고 적혀 있습니다.
- nizima 제휴(어필리에이트) 프로그램의 공개된 조건은 확인하지 못했습니다. nizima 판매 수익을 나눠 받는 구조는 현재로서는 기대하기 어렵습니다.

그래서 현실적인 구조는 다음과 같습니다.

```text
앱 → (링크) nizima 웹사이트 → 사용자가 구매·다운로드 → 앱에서 파일 가져오기
```

이 구조에서 개발자의 수익은 nizima 판매가 아니라 **앱 자체의 유료 기능(인앱결제)**에서 나와야 합니다.

### 5-2. 라이선스상 어떻게 되는가

- 모델을 가져오는 기능이 생기면 **확장성 앱**이 되어 개인 면제가 사라집니다. 사전 신청과 승인, 별도 계약이 필요합니다.
- 유료 기능이 있으면 "수익 모델" 요건은 충족합니다. 공식 안내상 완전 무료 앱은 원칙적으로 승인 대상이 아닙니다.
- **수수료** (공식 사이트 안내 기준, 일반 사용자·소규모 사업자):
  - 기본료는 없습니다.
  - **판매 1건당 ¥300 또는 매출의 20% 중 큰 금액**을 냅니다.
  - 매출 보고 의무가 있습니다.
- 승인은 Live2D 재량입니다. **Live2D와 nizima가 같은 콘셉트의 공식 앱 "My Live2D Clock(まいクロ)"을 운영 중입니다.** nizima 모델을 스마트폰 배경화면으로 쓰는 앱이고, 무료에 일부 기능만 유료입니다. 경쟁 앱으로 보일 수 있다는 점도 고려해야 합니다.
- nizima 모델마다 제작자가 정한 이용 범위가 있습니다. 우리 앱에서 쓰는 것이 허용된 모델인지 사용자에게 안내해야 합니다. 세부 조건은 아직 확인하지 못했습니다.

### 5-3. 수익 계산 예시 (가정)

가정은 다음과 같습니다.
- 스토어 수수료 15% (Apple·Google 소규모 개발자 요율)
- Live2D 수수료 = max(¥300, 판매가의 20%)
- 수수료를 어떤 금액 기준으로 계산하는지는 계약서로 확인해야 합니다.

| 판매가 | 스토어 수수료 | Live2D 수수료 | 남는 금액 |
|---:|---:|---:|---:|
| ¥500 | ¥75 | ¥300 | ¥125 (25%) |
| ¥1,000 | ¥150 | ¥300 | ¥550 (55%) |
| ¥1,500 | ¥225 | ¥300 | ¥975 (65%) |
| ¥3,000 | ¥450 | ¥600 | ¥1,950 (65%) |

건당 ¥300 최저 수수료 때문에 **저가 상품은 남는 게 거의 없습니다.**

### 5-4. 확장성 앱이 되지 않는 유료화

- 캐릭터를 앱에 고정으로 넣습니다.
- 앱 자체를 유료로 팔거나, 기능을 인앱결제로 팝니다. 예: 배경화면 꾸미기, 추가 모션·표정.
- 이 구조가 확장성 앱이 아니라면 **개인 개발자는 Live2D 계약과 수수료가 면제**되고 스토어 수수료만 냅니다.
- 다만 추가 캐릭터를 내려받게 하는 DLC는 "파일을 추가해 모델을 이용"하는 데 해당할 수 있어 확인이 필요합니다.
- 캐릭터는 직접 만들거나, **앱에 넣어 판매·배포하는 것까지 허용하는 조건**으로 제작을 의뢰합니다. nizima에서도 주문 제작을 받습니다.

### 5-5. Live2D에 문의할 내용

1. 캐릭터 고정 + 따라하기 + Android 배경화면 구성이 확장성 앱에 해당하는지
2. nizima 모델 가져오기 + 유료 기능 구조의 승인 가능성과 조건
3. nizima 연동 방법이나 제휴 프로그램이 있는지

답변을 받기 전까지는 모델 가져오기 기능을 구현하지 않습니다.
