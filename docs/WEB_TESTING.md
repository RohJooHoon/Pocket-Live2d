## 1. 준비

- Node.js 20.19 이상 (22 권장), Python 3.9 이상
- 처음 한 번 실행합니다.
  ```bash
  npm install
  ```
- 캐릭터를 보려면 Cubism SDK for Web을 준비합니다. 방법은 [Cubism SDK 설정](CUBISM_SDK_SETUP.md)에 있습니다.
  ```bash
  python3 tool/prepare_cubism_web.py ~/Downloads/CubismSdkForWeb-5-r.5
  ```

## 2. PC에서 실행

```bash
npm run dev
```

- 브라우저에서 `http://localhost:5173`을 엽니다.
- 다른 캐릭터를 열려면 `CHARACTER`를 지정합니다.
  ```bash
  CHARACTER=mark npm run dev            # macOS / Linux / Git Bash
  $env:CHARACTER="mark"; npm run dev    # Windows PowerShell
  ```
- PC에는 기울기 센서가 없으니 터치(마우스 드래그·클릭)와 버튼만 확인할 수 있습니다.

## 3. 휴대폰·태블릿에서 실행

**기울이기·흔들기는 `https` 주소에서만 동작합니다.** 브라우저 보안 정책 때문입니다. 그래서 휴대폰 테스트는 https 개발 서버로 합니다.

1. PC와 휴대폰을 **같은 Wi-Fi**에 연결합니다.
2. PC에서 실행합니다.
   ```bash
   npm run dev:https
   ```
3. 터미널에 나오는 `Network: https://192.168.x.x:5173/` 주소를 휴대폰 브라우저에 입력합니다.
4. 인증서 경고가 나오면 계속합니다. 개발용 자체 서명 인증서라서 정상입니다.
   - iPhone Safari: "자세한 정보 보기" → "이 웹 사이트 방문"
   - Android Chrome: "고급" → "안전하지 않음으로 이동"
5. 접속이 안 되면 PC 방화벽이 5173 포트를 막고 있는지 확인합니다.

빌드한 결과를 그대로 확인하려면 다음을 실행합니다.

```bash
npm run build && npm run preview
```

이때는 http라서 휴대폰의 기울이기는 동작하지 않습니다.

## 4. 화면 이해하기

```text
┌──────────────────────────────┐
│ Mark-kun                  ⓘ │  ⓘ: 저작권 표기, 이용약관, 개인정보처리방침
│                              │
│        (캐릭터 영역)          │  드래그 = 시선, 짧게 탭 = 반응
│                              │
│        상태 메시지            │  불러오는 중 / SDK 안내 / 오류 / 안내
│ [기울이기·흔들기 켜기][반응][표정] │
└──────────────────────────────┘
```

| 상태 메시지 | 의미 |
|---|---|
| 캐릭터를 불러오고 있어요. | 모델 로딩 중 |
| (메시지 없음) | 정상. 캐릭터 표시 중 |
| Live2D SDK가 연결되지 않은 빌드예요. | SDK 없이 빌드됨. [SDK 설정](CUBISM_SDK_SETUP.md) 확인 |
| 이 브라우저에서는 캐릭터를 표시할 수 없어요. (WebGL 미지원) | 브라우저나 기기가 WebGL을 지원하지 않음 |
| 캐릭터를 불러오지 못했어요. 새로고침해 주세요. | 모델 파일 로드 실패. 브라우저 개발자 도구 콘솔에 원인이 남음 |
| 기울이기는 https 주소에서만 쓸 수 있어요. | http로 접속함. [3장](#3-휴대폰태블릿에서-실행)대로 https로 접속 |
| 동작 및 방향 접근이 거부됐어요. | iPhone 권한 팝업에서 거부함. [8장](#8-문제-해결) 참고 |

| # | 어떻게 | 정상이면 |
|---|---|---|
| G-1 | 다른 탭으로 갔다가 돌아오기 | 캐릭터가 이어서 움직임. 기울이기는 돌아온 자세가 새 기준 |
| G-2 | 화면 잠금 후 해제 | 정상 복귀 |
| G-3 | 가로 화면에서 다른 탭으로 갔다가 돌아오기 | 세로 안내가 유지됨. 세로로 돌린 뒤에만 캐릭터·센서가 재개됨 |

모바일은 세로 화면에서만 조작할 수 있습니다. 일반 웹 탭에서는 방향 잠금이 지원되지 않거나 전체 화면에서만 허용됩니다.
지원되는 환경에서는 `screen.orientation.lock('portrait')`를 시도하며, 잠글 수 없는 환경에서는 가로 화면을 세로 안내로 덮습니다.
가로 안내가 떠 있는 동안 열려 있던 동의·정보·약관 창을 닫지 않으며, 센서 켜짐 설정도 유지합니다.

## 6. 박람회 태블릿 설정

- **페이지 고정**
  - iPad: `설정` → `손쉬운 사용` → `사용법 유도`를 켭니다. Safari에서 페이지를 연 뒤 측면 버튼을 세 번 눌러 시작합니다.
  - Android: `설정` → `보안` → `앱 고정`(화면 고정)을 켭니다. 최근 앱 화면에서 브라우저를 고정합니다.
- **화면 꺼짐 방지**
  - iPad: `설정` → `디스플레이 및 밝기` → `자동 잠금` → `안 함`
  - Android: `디스플레이` → `화면 자동 꺼짐`을 최대로 하거나, 충전 중 화면 켜짐 유지(개발자 옵션)를 켭니다.
- **충전기를 연결해 두세요.** 장시간 시연은 배터리를 많이 씁니다.
- **동의 화면은 미리 넘겨 두세요.** 행사 시작 전에 한 번 동의해 두면 이후로는 바로 캐릭터가 나옵니다.
- **거치대에 세운 태블릿은 기울이기를 꺼 두는 게 좋습니다.** 터치 반응 위주로 시연합니다.
- 태블릿 앞에는 같은 캐릭터 사이트의 **QR 코드**를 둡니다. 관람객이 자기 휴대폰으로 열어 기울이기·흔들기를 직접 해 볼 수 있습니다.

## 7. 배포와 QR 코드 (Cloudflare Pages)

캐릭터 사이트는 **Cloudflare Pages에 직접 업로드**합니다.

- **SDK가 준비된 PC에서 빌드한 폴더를 올립니다.** 그래야 결과물에 Core와 셰이더가 들어갑니다.
- **Cloudflare의 GitHub 연동 자동 빌드는 쓰지 않습니다.** Cloudflare 서버에는 SDK가 없어서 "SDK 연결 필요" 페이지가 올라가고, SDK를 저장소에 넣을 수도 없기 때문입니다.
- 이렇게 올리면 Cubism Core가 git에 남지 않습니다.
- 주소는 기본으로 https입니다 (`<프로젝트>.pages.dev`).

### 처음 한 번

1. [Cloudflare](https://dash.cloudflare.com/sign-up) 계정을 만듭니다 (무료 플랜으로 충분).
2. Node.js 22 이상인지 확인합니다 (`node -v`). 업로드 도구(Wrangler)가 22 이상을 요구합니다.
3. 로그인합니다. 브라우저가 열리면 허용을 누릅니다.
   ```bash
   npx wrangler login
   ```

### 올리기 (명령 한 번)

```bash
npm run deploy -- mark
```

이 명령이 순서대로 하는 일은 다음과 같습니다.
1. SDK가 준비됐는지 확인합니다. 없으면 멈춥니다.
2. `dist/mark/`를 빌드합니다.
3. 결과물에 Core가 들어 있는지 확인합니다.
4. Cloudflare Pages 프로젝트 `motionmate-mark`를 만듭니다 (이미 있으면 건너뜀).
5. 업로드합니다.

- 끝나면 `https://motionmate-mark.pages.dev` 주소가 나옵니다.
- 프로젝트 이름을 바꾸려면 `characters/<id>/character.json`에 `"pagesProject": "원하는-이름"`을 넣습니다. 소문자, 숫자, `-`만 쓸 수 있습니다.
- 올리기 전에 명령만 확인하려면 `npm run deploy -- mark --dry-run`을 실행합니다.

### 대시보드에서 직접 올리기 (명령어 없이)

1. `npm run build`로 `dist/mark/`를 만듭니다. Windows는 `$env:CHARACTER="mark"; npm run build`로 실행합니다.
2. Cloudflare 대시보드 → **Workers & Pages** → **Create** → **Pages** → **Upload assets**를 엽니다.
3. 프로젝트 이름을 정하고 `dist/mark` 폴더를 끌어다 놓습니다.
4. 다음 버전부터는 같은 프로젝트의 **Create deployment**로 새 폴더를 올립니다.

### 캐릭터별 도메인 연결

1. 대시보드 → **Workers & Pages** → 프로젝트 → **Custom domains** → **Set up a custom domain**으로 갑니다.
2. `mark.example.com`처럼 캐릭터별 주소를 입력합니다.
   - 도메인을 Cloudflare에서 관리하면 DNS가 자동으로 연결됩니다.
   - 다른 곳에서 관리하면 안내대로 `CNAME`을 `<프로젝트>.pages.dev`로 추가합니다.
3. 인증서가 자동으로 발급되어 https로 열립니다. 몇 분 걸릴 수 있습니다.

### 함께 올라가는 설정

빌드할 때 `deploy/cloudflare/_headers`가 함께 들어갑니다.
- 모델과 스크립트 파일의 캐시 시간을 정합니다.
- 카메라는 이 사이트에서 이용자가 허용한 경우에만 사용하도록 설정합니다. 마이크·위치는 차단합니다.

### QR 코드

- 배포한 https 주소로 QR 코드를 만듭니다. 아무 QR 생성기나 써도 됩니다.
- 인쇄하기 전에 휴대폰 2대 이상으로 스캔해서 주소가 맞는지 확인합니다.

### 배포 후 확인

| # | 어떻게 | 정상이면 |
|---|---|---|
| J-1 | 배포 주소를 https로 열기 | 자물쇠 표시, 캐릭터 표시 (SDK 안내 문구가 없어야 함) |
| J-2 | QR 코드 스캔 | 같은 주소가 열림 |
| J-3 | 이용약관·개인정보처리방침 열기 | 자리표시자(`[운영자 이름]` 등)가 남아 있지 않음 |
| J-4 | 기울이기 켜기 | 휴대폰에서 동작함 |
| J-5 | 커스텀 도메인으로 열기 | https로 열리고 `pages.dev` 주소와 같은 화면 |

## 8. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "Live2D SDK가 연결되지 않은 빌드예요" | `vendor/cubism/`이 있는지 확인. 없으면 `python3 tool/prepare_cubism_web.py <SDK 폴더>` 실행 후 다시 `npm run dev` 또는 `npm run build` |
| 준비 스크립트가 "This is the Cubism SDK for Native" | Native SDK를 넣은 경우. **Cubism SDK for Web**을 받아서 다시 실행 |
| 캐릭터를 불러오지 못했어요 | 브라우저 개발자 도구 콘솔의 `Live2D:` 메시지 확인. 모델 파일 이름, model3.json 참조 확인. `npm run validate:models` 실행 |
| 기울이기 버튼을 눌러도 https 안내만 나옴 | http로 접속함. `npm run dev:https`나 배포한 https 주소로 접속 |
| iPhone에서 권한을 거부함 | Safari를 완전히 닫았다 다시 열고 다시 시도. 계속 거부되면 `설정` → `Safari` → `고급` → `웹 사이트 데이터`에서 해당 사이트 데이터를 지운 뒤 다시 접속 |
| 휴대폰에서 개발 서버 주소가 안 열림 | 같은 Wi-Fi인지, PC 방화벽이 5173 포트를 허용하는지 확인 |
| 캐릭터가 흐릿함 | 화면 밀도는 최대 2배로 제한됨 (배터리 절약). 의도된 동작 |
