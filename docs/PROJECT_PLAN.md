# Pocket Live2D 개발 계획과 진행 상태

목표: 기울이기·흔들기·터치·얼굴 움직임에 반응하는 Live2D 캐릭터를 **URL 경로별로 읽는 웹사이트**로 공개합니다. 모델은 R2에 추가하고 사이트 코드는 재배포하지 않는 구조를 지원합니다.

갱신: 2026-10-08. 체크된 항목은 **코드 구현 또는 문서 준비**를 뜻합니다.
SDK를 넣은 실제 표시와 기기 검증은 따로 체크합니다.

## 방향 전환 기록

- Flutter 앱(iOS/Android, Android 라이브 배경화면, 얼굴 따라하기)에서 **웹으로 전환**했습니다. 앱 코드는 git 기록에 남아 있습니다.
- 이유는 다음과 같습니다.
  - 스토어 심사와 결제 규정 없이 QR로 바로 체험시키려는 목적
  - 단일 모델 사이트는 일반 앱과 같은 면제 범위를 검토할 수 있었음. URL별 여러 모델을 읽는 구조에서는 이 판단을 다시 확인해야 함
  - 박람회와 외주 홍보에 맞는 형태
- 얼굴 따라하기는 2026-10-08 요청으로 다시 추가했습니다. 기능 구현과 공개 라이선스 판정은 별개이며, 고정 모델 웹사이트가 확장성 애플리케이션에 해당하는지는 확인이 필요합니다. 근거는 [라이선스 문서](LICENSING.md)에 있습니다.
- 같은 날 URL 경로로 여러 모델을 읽는 구조를 추가했습니다. 기존의 단일 모델·독립 도메인 가정은 현재 기본 구조의 라이선스 판단 근거로 사용하지 않습니다.

## 1. 웹 기반

- [x] Vue 3 + TypeScript + Vite 프로젝트, 캐릭터별 빌드 (`CHARACTER=<id>`)

- [x] Core 확인 뒤 Framework를 별도 파일로 불러오기 (Core가 없어도 페이지가 멈추지 않음)

- [x] 공개 CI: 단위 테스트, 타입 검사, 모델 검사, 캐릭터별 빌드, SDK 파일 유출 검사
- [x] 휴대폰 테스트용 https 개발 서버
- [x] 모바일 세로 전용: 지원 환경에서 방향 잠금 시도, 가로에서는 세로 안내로 조작 차단 (다이얼로그·센서 설정 유지)
- [x] `/이름` → 저장소 `models/이름/character.json` → 같은 폴더 모델, R2 주소 최초 설정 후 데이터 업로드만으로 추가
- [x] 모델 업로드 준비 스크립트: 참조 파일 검사·복사, 모션 그룹·저작권 고지 유지, 메타데이터 생성

## 다음 순서

1. Cubism SDK for Web을 준비하고 `npm run dev`로 Mark 표시를 확인합니다.
2. 휴대폰(`npm run dev:https`)에서 [웹 테스트 가이드](WEB_TESTING.md)의 A~G를 확인합니다.
3. `npx wrangler login` 후 `npm run deploy -- mark`로 Cloudflare Pages에 올려 휴대폰에서 확인합니다.
4. 직접 만든 캐릭터를 넣고 사이트별로 배포합니다.
5. 약관 자리표시자와 서비스 이름을 확정합니다.
6. 박람회 전에 태블릿 장시간 테스트와 Live2D 문의를 마칩니다.

## 구조

- `src/`: 페이지, 입력 처리, 약관, 렌더러
- `legal/`: 이용약관, 개인정보처리방침
- `characters/<id>/`: 캐릭터 설정과 모델
- `tool/`: SDK 준비, 정적 파일 준비, 모델 검사
- `vendor/cubism/`: 로컬에만 두는 Cubism SDK (git 제외)
